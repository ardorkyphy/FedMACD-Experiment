# Third-party input data

The three continuous MATMCD tables and the 10nodes input are available from the pinned upstream repositories linked in [`DATASETS.md`](DATASETS.md). Their study-tree inputs have been checked against those sources; the exact conversion steps and local checksums are recorded there. The bnlearn BIF inputs can be downloaded from the links in that guide, with checksum validation and historical Asia block-order restoration as described there.

This repository does not rehost third-party source files. Obtain them from their respective upstream repositories and follow the terms stated by those sources. The ER20 table is generated by the study code and is not a third-party input; its regeneration was checked against the historical matrix to floating-point precision. Generated Bayesian-network observations depend on the sampling and split configuration and are not byte-identical across seeds.
