# Third-party study data limitations

Auto_MPG (392 x 5), DWD_climate (349 x 6), Sachs (7466 x 11), and 10nodes (5000 x 10) are not redistributed. `DATASETS.md` records the known source link, columns, preprocessing, and graph convention. The historical local-file checksums are provenance records, not hashes of identified public downloads.

Exact upstream version, raw file locator, redistribution terms, and a verified byte-identical reconstruction chain remain unresolved. The Sachs bnlearn link is a background network reference, not the continuous study table. The 10nodes URL is unknown. These gaps prevent a complete ten-dataset reproduction from the public archive alone. Do not infer an exact reconstruction from dimensions or rename regenerated data as historical inputs.
